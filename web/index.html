ABOUT GITNOTE

发现值得一看的
GitHub 项目。

打开页面会自动发现一批项目；“换一批”从不同话题、Stars 区间和排序生成 GitHub 搜索条件，每次最多抽样三轮，再按本地兴趣画像排序。搜索、Stars 总榜和 Trending 使用各自的远程数据源。推荐逻辑参考 GitTok.dev 当前公开实现，具体来源和许可见 README。

01推荐与探索

话题和语言偏好影响搜索与排序，也会保留探索机会。

02登录与额度

OAuth 凭据仅留在本机 Python 进程，登录后由后端发送认证搜索请求。断开后如需撤销 GitHub 端授权，可在 GitHub Applications 操作。

03数据留在本地

画像存在浏览器 localStorage，可随时重置。不会上传停留时长到第三方。
